# UnseenFruit - 无形果实模组

![Minecraft](https://img.shields.io/badge/Minecraft-1.7.10-brightgreen)
![Forge](https://img.shields.io/badge/Forge-1.7.10--10.13.4.1614-orange)
![License](https://img.shields.io/badge/License-MIT-blue)

一个神秘的 Minecraft 模组，添加了看不见的果实和相关的种植系统。

## ✨ 特性

- **无形果实**：食用后获得特殊效果
- **种植系统**：可以通过种子种植并获得更多果实
- **铁制工具**：新增铁锥、铁针等工具
- **音效系统**：完整的破坏、种植、食用音效

## 🎮 使用方法

### 1. 获取无形种子
- 打草时有 50% 几率掉落
- 或用无形果实在工作台合成

### 2. 种植
- 右键耕地上种植无形种子
- 等待生长（约10秒/阶段）
- 成熟后右键收获

### 3. 食用无形果实
- 右键食用
- 获得粉红眼效果
- 随机获得夜视效果

## 🔧 安装

1. 下载最新版本的 `.jar` 文件
2. 放入 Minecraft 的 `mods/` 文件夹
3. 启动游戏享受！
